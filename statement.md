# Project Statement

## Problem Statement
Driver fatigue and prolonged eye closure can reduce attention while driving. This project develops a real-time computer vision prototype that monitors a driver's face and eyes through a webcam and raises an alert when prolonged eye non-detection is observed.

## Scope
The project covers webcam-based face detection, eye detection, frame-based drowsiness decision, audible alerting, and session logging. It is a prototype for academic demonstration and is not a certified automotive safety system.

## Target Users
- Students learning computer vision
- Academic demonstrators
- Researchers prototyping driver-monitoring systems

## High-Level Features
1. Real-time face detection
2. Eye detection inside the detected face
3. Consecutive closed-eye-frame monitoring
4. Drowsiness status classification
5. Audible warning
6. CSV session logging
7. Session statistics
